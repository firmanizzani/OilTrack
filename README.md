# OliTrack - Oil Change Tracking Application

OliTrack is a web application for recording and monitoring vehicle oil change history personally.

## Features
- **Dashboard & Analytics:** Summary statistics, 6-month spending bar chart, and vehicle service status overview.
- **Vehicle Management:** Add and manage cars or motorcycles with brand, year, and license plate details.
- **Oil Change History:** Log every oil change with date, odometer, oil type, price, and workshop info.
- **Smart Reminder System:** Customizable km and month intervals per vehicle with automatic status indicators (Safe, Due Soon, Overdue).
- **Authentication:** Secure register and login with JWT-based authentication.

## Tech Stack
**Frontend:** React, TypeScript, Vite, Tailwind CSS, Recharts, Zustand  
**Backend:** Node.js, Express.js, Prisma ORM, PostgreSQL  
**Deployment:** Vercel
